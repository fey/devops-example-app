# AGENTS.md

Учебное приложение курса «Деплой на PaaS». Поведение по HTTP из таблицы в README общее для всех приложений `paas-*-app`, на него опираются уроки курса. Маршруты, тексты ответов, формат строки лога, переменные `PORT`, `SERVER_MESSAGE`, `SENTRY_DSN` и `DATABASE_URL`, таблица `page_visits` и строка счётчика меняются только вместе с остальными приложениями и уроками.

Изменение готово, когда проходят `mise run check` и `mise run test`. Правила линтеров не отключаются ради прохождения проверки.
